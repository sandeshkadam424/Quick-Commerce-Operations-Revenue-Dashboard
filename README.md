## Project Overview

This project is an interactive Power BI dashboard designed to analyze quick-commerce operations, revenue, order trends, and delivery performance.

The dashboard uses 500 orders from January to October 2026 across 3 platforms and 8 Indian cities.

## Key Performance Indicators

| KPI | Value |
|---|---:|
| Net Delivery Revenue | ₹208.32K |
| Total Orders | 500 |
| Average Order Value | ₹445.26 |
| Average Delivery Time | 26.06 min |
| Cancellation & Refund Rate | 7.00% |

## Key Business Insights

- Net delivery revenue reached ₹208.32K during the analyzed period.
- The average order value was ₹445.26.
- Average delivery time for delivered orders was 26.06 minutes.
- The cancellation and refund rate was 7.00%.
- Platform and city filters allow users to explore performance across different locations and platforms.

## Recommendations

- Monitor cities with delivery times above the overall average.
- Investigate reasons behind cancellations and refunds.
- Compare revenue contribution across delivery platforms.
- Analyze monthly order and revenue trends to support planning.
- Use category and item-level analysis to improve product availability.
